## التشغيل

يتطلب Node.js 20 أو أحدث، ولا يحتاج `npm install`.

### واجهة العمل

```bash
npm start
```

ثم افتح `http://localhost:4173/app/`.

| الشاشة | ماذا فيها |
| --- | --- |
| **مكتبي** | ملخص اليوم، أولويات صندوق العمل، مؤشرات الشركة، ما حدث أمس، خارطة الطريق |
| **مهامي** | الرسائل والشكاوى والمستندات: اختيار القرار مع تبرير مكتوب، أو كتابة المستند وتسليمه، ثم رؤية النتيجة |
| **فريقي** | الزملاء والمديرون، شخصياتهم وما يهمهم، وثقة كل منهم بك |
| **الاجتماعات** | اجتماعات اليوم والسابقة |
| **ملفات الشركة** | المنتج، تقرير استخدام الخصائص، الحسابات الاستراتيجية ورضاها، المنافسون، الهيكل |
| **نتائج الشركة** | الإيرادات والعملاء والرضا والنقد والجودة والدعم يومًا بيوم |
| **سجل الشركة** | كل ما حدث ولماذا |
| **تطورك المهني** | السجل المهني القائم على الأدلة، مع المقارنة بعالم لم يتخذ فيه أحد أي قرار |

**إنهاء يوم العمل** يحذّر من البنود التي ستنتهي مهلتها، ثم يعرض ملخص اليوم: "هذا ما حققته بقراراتك". التقدم يُحفظ في المتصفح، فتعود في اليوم التالي وتجد شركتك كما تركتها. الحفظ لا يخزن حالة الشركة، بل البذرة وسلسلة الأفعال فقط، ويعيد المحرك الحتمي بناء العالم منها، فيكون سجل تدقيق كاملًا في الوقت نفسه.

فحص آلي للواجهة في متصفح حقيقي على سطح المكتب والجوال (يتطلب Playwright، وأن يكون الخادم يعمل):

```bash
node scripts/ui-smoke.js
```

### المحرك والعرض التوضيحي

```bash
npm test
```

```bash
npm run demo
```

العرض التوضيحي يشغّل متدربًا افتراضيًا يعيش الشهر كاملًا: يرد على الشكاوى، يتخذ قرارات خارطة الطريق، يسلّم التحليلات والعروض ووثيقة المتطلبات، ثم يطبع **السجل المهني** ويقارن نتائج الشركة بعالم موازٍ مطابق لم يتخذ فيه أحد أي قرار.

```bash
npm run demo -- --seed 42 --quiet
```

## استخدام المحرك برمجيًا

```js
import { Simulation, loadCompany, loadScenario } from './src/index.js';

const sim = new Simulation({
  company: loadCompany('nova-tech'),
  scenario: loadScenario('pm-first-30-days'),
  seed: 7,                        // نفس البذرة = نفس العالم (عدالة التقييم)
});

sim.inbox();                      // رسائل، مهام، اجتماعات، شكاوى مرتبة حسب الأولوية
sim.respond('d1_ufuq_complaint', 'call_and_plan', { rationale: 'العميل استراتيجي...' });
sim.submitDeliverable('d1_usage_report', 'المشكلة: ... التوصية: ...');
sim.endDay();                     // تنتهي المهلات، تعمل الشركة، وتظهر النتائج
sim.dashboard();                  // مركز الشركة: النقد، الإيرادات، العملاء، الجودة، الثقة
sim.report();                     // السجل المهني القائم على الأدلة
```

## المبدأ التقني الأهم

**الذكاء الاصطناعي يدير الحوار، والقواعد تحكم النتائج.** الأرقام المالية والتشغيلية تحسبها معادلات صريحة في `src/engine/economy.js`، وكل قرار يغيّر الشركة عبر "آثار" مكتوبة وقابلة للتدقيق، وكل درجة في التقييم مرتبطة بدليل محفوظ. التفاصيل في [`docs/03-simulation-engine.md`](docs/03-simulation-engine.md).

> محاكي تمنح أدلة عملية على المهارات داخل بيئة افتراضية، ولا تدّعي أن المستخدم عمل لدى شركة حقيقية. NOVA TECH وكل شخصياتها وعملائها ومنافسيها خيالية.

## الترابط: كيف تتسلسل العواقب

**سلسلة مجموعة الأفق**

```
اليوم 1: الشكوى
 ├─ اتصلت وفهمت المشكلة ──────────► رضا +12
 ├─ وعدت بإصلاح خلال 10 أيام ────► رضا +16 الآن، ووعد مسجّل
 │     └─ اليوم 3: هل اخترت إصلاح التقارير؟
 │           ├─ نعم ─► يُطلق نحو اليوم 10 ─► رضا +22، الوعد محفوظ
 │           └─ لا  ─► اليوم 11: "مرّ موعد الإصلاح" ─► رضا −25، ثقة خالد وأمل تنخفض
 └─ تجاهلت ──► رضا −18 (يصبح 16) ─► احتمال خسارة الحساب يوميًا
                                    └─ حدث "الأفق على وشك الإلغاء" ─► فرصة أخيرة
```

**سلسلة التحليل والعرض**

```
تحليل التقارير (اليوم 3) ─ جيد ─► ثقة خالد +8
عرض الإدارة (اليوم 5) ─ جيد ─► ميزانية تسويق +15,000/شهر ─► عملاء جدد أكثر طوال الشهر
                      ─ ضعيف ─► لا ميزانية
                      ─ لم يُسلَّم ─► تأجيل الاجتماع، ثقة الرئيس التنفيذي −10
```

**سلسلة الفريق**

```
اليوم 3: "ابدأوا الثلاثة معًا" ─► الروح المعنوية −8 ─► تطوير أبطأ لكل البنود
اليوم 18: تجاهل إرهاق نورة ─► بعد 4 أيام تستقيل ─► سعة التطوير −0.9 يوميًا
اليوم 15: إلغاء أدوات التطوير ─► سعة −0.4 ─► بنود الطريق تتأخر
```

# 12 — خطة الاختبار وتقليل التكاليف

> القرار: **الاختبار أولًا بأقل تكلفة**. الدخول عبر نفاذ مؤجل إلى ما بعد التجربة.

## من أين تأتي التكلفة

| البند | طبيعته | في التجربة المغلقة |
| --- | --- | --- |
| **استدعاءات Claude** | متغيرة: كل جولة في اجتماع أو محادثة، وكل رسالة لزميل | **أهم بند يمكن التحكم فيه**. التفاصيل أدناه |
| الخادم | ثابتة شهريًا | خادم صغير واحد يكفي لعشرات المتدربين (Node.js بملفات JSON، دون قاعدة بيانات) |
| البريد | شبه معدومة | رسائل قليلة لكل متدرب (تأكيد، واستعادة). في الاختبار الداخلي: الصندوق الصادر دون مزوّد |
| التطوير | — | لا مكتبات مدفوعة، ولا خدمات خارجية غير Claude |

## تكلفة Claude بالأرقام

تقدير من التعليمات **الفعلية** التي يرسلها المنتج لكل جولة في كل حوار بالسيناريو (`node scripts/estimate-cost.js`). لكل متدرب نحو 15 استدعاء اجتماعات، و35 استدعاء محادثات، و15 رسالة زملاء.

| الملف | ماذا يستخدم | لكل متدرب | لـ50 متدربًا |
| --- | --- | --- | --- |
| `offline` | الوضع المحلي لكل شيء | 0 | 0 |
| **`economy` (الافتراضي)** | Haiku 5.5 للاجتماعات والمحادثات، والمراسلة محلية | **نحو 0.07–0.10 ر.س** | **نحو 3–5 ر.س** |
| `balanced` | Sonnet 5.5 للاجتماعات، وHaiku 5.5 للبقية | نحو 0.5–0.8 ر.س | نحو 24–38 ر.س |
| `quality` | Opus 5.5 لكل شيء | نحو 3–6 ر.س | نحو 156–302 ر.س |

**الهامش:** النطاق بين ردود قصيرة (400 توكن إخراج) وطويلة (800). العدّ تقدير من طول النص العربي بهامش ±40%. مع مفتاح API يعاير السكربت النسبة بنقطة عدّ التوكنات الرسمية (مجانية).

**الخلاصة:** في التجربة المغلقة، تكلفة الذكاء الاصطناعي ليست العائق، حتى بملف `balanced`. **السؤال الحقيقي هو الجودة:** هل يحكم Haiku على الاعتراضات بدقة كافية؟ لأن حكمه يدخل في نقاط المتدرب.

## ما بُني لتقليل التكلفة وضبطها

| الإجراء | الأثر |
| --- | --- |
| **ملفات تكلفة** `MOHAKI_AI_PROFILE=economy\|balanced\|quality\|offline` | تبديل النموذج لكل مسار بمتغير واحد، مع تجاوز مسار بعينه: `MOHAKI_MODEL_MEETING=claude-sonnet-5-5` |
| **الضيف يعمل محليًا** (`MOHAKI_AI_GUESTS=claude` لتغييره) | لا تكلفة على زوار يجربون اليوم الأول ثم يغادرون. Claude للمسجلين فقط |
| **سقف يومي للمنصة** `MOHAKI_AI_DAILY_BUDGET_USD` (الافتراضي 5 دولارات) | يستحيل أن تتجاوز التكلفة السقف. عند بلوغه يكمل الجميع بالوضع المحلي تلقائيًا |
| **سقف يومي لكل مستخدم** `MOHAKI_AI_USER_DAILY_CALLS` (الافتراضي 150 استدعاءً) | يمنع مستخدمًا واحدًا (أو سكربتًا) من استهلاك الميزانية |
| **تخزين مؤقت أفضل للتعليمات** | الجزء الثابت من كل حوار (الموضوع والمعايير والسياق السعودي) يُخزن، فتقرأه الجولات التالية بعُشر السعر |
| **جهد منخفض** (`effort: low`) | تفكير أقل وتوكنات إخراج أقل. مناسب للحوار |
| **مراسلة الزملاء محلية في `economy`** | المراسلة لا تُقيَّم، والرد المحلي يعطي الأرقام نفسها من المعرفة المخزنة |
| **عدّاد الاستخدام الفعلي** `GET /api/admin/usage` (برمز `MOHAKI_ADMIN_TOKEN`) | التكلفة الحقيقية يوميًا لكل مسار ونموذج، وعدد المستخدمين والاستدعاءات، من `usage` الذي تعيده Anthropic |

**ملاحظة تقنية:** Haiku 5.5 لا يدعم البديل التلقائي عند الرفض. الكود يرسله فقط للنماذج التي تدعمه، وإلا لفشلت الطلبات.

## خطة الاختبار

### المرحلة 0 — اختبار داخلي (مجاني)
`MOHAKI_AI_PROFILE=offline`

- الفريق يلعب السيناريو كاملًا بالوضع المحلي.
- الهدف: إيجاد أخطاء التجربة والمحتوى (نصوص، ومهلات، وأوزان) قبل أي تكلفة.
- يُراجع المحتوى مع مدير منتجات يعمل في السوق السعودي.

### المرحلة 1 — فحص جودة Haiku (بضع هللات)
- حساب تجريبي واحد بملف `economy`، ثم الحوارات نفسها بملف `balanced`.
- عينة من نحو 30 ردًا في الاجتماعات: قوية، وضعيفة، ومراوغة، ومحاولات تلاعب.
- المقارنة: هل حكم Haiku على كل اعتراض يطابق حكم Sonnet وحكم مراجع بشري؟
- **القرار:** إن تطابق في الأغلب، يبقى `economy`. وإلا، `MOHAKI_MODEL_MEETING=claude-sonnet-5-5`، وتبقى المحادثات على Haiku.

### المرحلة 2 — تجربة مغلقة (30–50 متدربًا)
- خريجون وطلاب من جامعة واحدة أو جامعتين، بالملف المختار في المرحلة 1، وسقف يومي منخفض.
- مدة كل متدرب نحو ستة أسابيع، بجلسة يومية من 20 إلى 40 دقيقة.

**ما نقيسه:**

| المؤشر | كيف |
| --- | --- |
| الإكمال | نسبة من وصلوا إلى اليوم 30 وأصدروا السجل |
| الواقعية | استبيان قصير: هل شعرت أنك موظف فعلًا؟ أي حدث بدا غير واقعي؟ |
| عدالة التقييم | مراجع بشري يقيّم عينة من السجلات، ونقارن بنقاط المنصة |
| التكلفة الفعلية | `/api/admin/usage` يوميًا، مقارنة بالتقدير |
| قيمة السجل | عرض سجلات مجهولة الهوية على جهة توظيف واحدة على الأقل: هل تفيدها في الفرز؟ |

### بعد التجربة
- يُعاير السيناريو والأوزان والحدود (700 نقطة، و50%) من النتائج.
- ثم تأتي متطلبات الإطلاق العام: قاعدة بيانات داخل المملكة، وترخيص البرامج، ومراجعة قانونية لنقل نصوص المحادثات، ونفاذ عند الحاجة.

## تشغيل التجربة المغلقة

```bash
ANTHROPIC_API_KEY=... MOHAKI_AI_PROFILE=economy MOHAKI_AI_DAILY_BUDGET_USD=2 MOHAKI_ADMIN_TOKEN=... MOHAKI_EMPLOYER_TOKEN=... MOHAKI_PUBLIC_URL=https://... MOHAKI_SECURE_COOKIE=1 npm start
```

لمتابعة التكلفة الفعلية يوميًا:

```bash
curl -H "Authorization: Bearer $MOHAKI_ADMIN_TOKEN" https://.../api/admin/usage
```

**الاستضافة:**
- خادم صغير واحد يكفي (1–2 معالج، و2 جيجابايت ذاكرة).
- يُفضَّل مزوّد له منطقة داخل المملكة، لأن بيانات المتدربين بيانات شخصية (انظر حدث سنابل في السيناريو، و`09`).
- راجع أسعار المزودين وقت التعاقد.

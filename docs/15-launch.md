# 15 — الدومين والموقع والنشر

> الهدف: موقع يقيس الطلب على العروض الثلاثة (يوم العمل التجريبي، تمهير، المديرون الجدد) قبل أن نبني أكثر، والمنصة نفسها على النطاق نفسه.

## ما بُني

| الجزء | الرابط | الوصف |
| --- | --- | --- |
| الصفحة الرئيسية | `/` | العرض الأول: **قيّم المرشح بيوم عمل، لا بمقابلة** |
| تمهير | `/tamheer` | برنامج جاهز للمنشآت المستضيفة لمتدربي تمهير |
| المديرون الجدد | `/managers` | محاكاة أول 30 يومًا كمدير |
| الخصوصية | `/privacy` | نسخة المرحلة التجريبية (تحتاج مراجعة قانونية قبل الإطلاق العام) |
| المنصة | `/app/` | المحاكاة نفسها، كما هي |
| روابط المشاركة | `/c/…` · `/p/…` | التحدي وملف الأعمال |
| فحص الصحة | `/healthz` | لمزوّد الاستضافة |

- **نموذج طلب عرض** في كل صفحة، يحفظ الطلب ويرسل إشعارًا إلى `MOHAKI_LEADS_EMAIL`. فيه حقل فخ للبرامج الآلية، وحد 5 طلبات في الساعة لكل عنوان.
- **عدّاد زيارات دون كوكيز:** عدد زيارات يومي لكل صفحة فقط. لا يحفظ عنوان IP ولا أي معرّف للزائر، فلا يحتاج نافذة موافقة على الكوكيز.
- **لوحة القياس:** الزيارات والطلبات ونسبة التحويل لكل عرض:
  ```bash
  curl -H "Authorization: Bearer $MOHAKI_ADMIN_TOKEN" https://<النطاق>/api/admin/leads
  ```
- **روابط الحملات:** أضف `?utm_source=linkedin&utm_campaign=hr-oct` لأي رابط، فيُحفظ مصدر كل طلب.

## النشر

صورة تشغيل واحدة (`Dockerfile`) تحتوي الواجهة والخادم والموقع. **البيانات في `/data` ويجب ربطه بمساحة تخزين دائمة**، وإلا ضاعت الحسابات والطلبات عند كل إعادة تشغيل.

### على Railway أو Render
1. اربط المستودع، ويُكتشف `Dockerfile` تلقائيًا.
2. أضف **مساحة تخزين دائمة** (Volume / Persistent Disk) على المسار `/data`.
3. أضف متغيرات البيئة (أدناه).
4. اربط النطاق من إعدادات الخدمة، وأضف سجل DNS الذي يطلبه المزوّد (عادة `CNAME`). شهادة HTTPS تصدر تلقائيًا.
5. افتح `https://<النطاق>/healthz`، والمفروض أن يرد `ok`.

### متغيرات البيئة

| المتغير | مطلوب؟ | القيمة |
| --- | --- | --- |
| `MOHAKI_PUBLIC_URL` | نعم | `https://<النطاق>` (روابط البريد والمعاينات) |
| `MOHAKI_SECURE_COOKIE` | نعم | `1` (HTTPS) |
| `MOHAKI_ADMIN_TOKEN` | نعم | قيمة عشوائية طويلة (لوحة الطلبات وعدّاد التكلفة) |
| `MOHAKI_LEADS_EMAIL` | نعم | البريد الذي تصله طلبات الشركات |
| `MOHAKI_SMTP_URL` · `MOHAKI_MAIL_FROM` | للبريد الحقيقي | دونها تُحفظ الرسائل في `/data/outbox` ولا تُرسل |
| `MOHAKI_FACILITATORS` | للمُيسِّرين | قائمة بريد مفصولة بفواصل |
| `ANTHROPIC_API_KEY` | لاحقًا | دونه تعمل المحاكاة بالوضع المحلي مجانًا |
| `MOHAKI_AI_PROFILE` · `MOHAKI_AI_DAILY_BUDGET_USD` | لاحقًا | انظر `12` |
| `MOHAKI_EMPLOYER_TOKEN` | لاحقًا | قائمة المرشحين لجهات التوظيف |

**لا تضع المفاتيح في المستودع.** تُضاف في إعدادات الخدمة عند المزوّد فقط.

### النسخ الاحتياطي
كل البيانات ملفات JSON في `/data`. انسخ المجلد يوميًا (أغلب المزوّدين يوفرون لقطات للمساحة الدائمة). قبل الإطلاق العام: قاعدة بيانات داخل المملكة.

## الدومين
- **الاسم:** `mohaki` بالحروف اللاتينية، أقرب نطق لـ"محاكي".
- **الامتداد:** `.sa` أنسب للسوق السعودي، لكن تسجيله يتطلب شروطًا ومستندات من المركز السعودي لمعلومات الشبكة (SaudiNIC)، فراجعها. ومعه أو بدله `.com` أو `.ai`.
- **التوفر:** لم نتحقق منه آليًا. تحقق منه عند المسجّل.
- اجعل `www` تحوّل إلى النطاق الأساسي، أو العكس.
